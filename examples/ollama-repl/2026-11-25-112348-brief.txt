## README.md
# ollama-repl

- **Dedicated HTTP client**: `lib/ollama-client.js` uses `httpClient` with fresh LWS connections per prompt.  
- **Token streaming (default)**: `chatStream()` reads Ollama's DJSON stream via `getReader()`.  
- **File detection**: Paths/globs auto-resolved; dirs with `/` yield top-level + newest files; direct file imports parsed and noted.  
- **File exchange**: All files in/out tracked; diffs saved to `diffs/NNN-name.diff`; revertable via `patch -R`.  
- **File output**: `File: path` blocks written to project; other code blocks saved as `<model>-output-N.ext`.  
- **Project awareness**: `LIST:/READ:/RUN:` auto-executed proactively; `RUN:` requires approval via `confirm()`.  
- **Startup scan**: Shallow top-level listing (JS/C/HTML/CSS/MD) + `README.md`, `CMakeLists.txt` — no deep recursion.  
- **Session persistence**: `session.json` resumes state; `/clear` wipes it.  
- **QuickJS/qjs-modules**: `quickjs.h` and `qjs-modules` files attached; `LIST:/READ:` reaches sibling projects.  
- **Real editing**: qjs-modules' REPL enables up/down, ^R, Tab completion; history in `~/.<scriptname>_history`.  
- **Session log**: Timestamped entries in `session.log` — read-only, persistent.  
- **Thinking indicator**: Animated spinner with Star Trek, Monkey Island, Discworld, Indiana Jones quips; capped at `timeoutSecs` (15min).  

Direct use: `lib/ollama-client.js`, `gemini-client.js`, `openai-client.js` support `tools: [{ name, description, parameters }]` via `chat()`/`chatStream()`.  

{id, name, args} in tool calls; respond as `{role: 'tool', name, content}`. See `API.md` for round-trip. Architecture: `doc/ARCHITECTURE.md`.  

Requirements:  
--provider freellm: FREELLMAPI_URL, FREELLMAPI_KEY; model=auto unless --model.  
--provider ollama: model from ollama list; no default.  
--provider gemini: GEMINI_API_KEY.  
--provider openai: OPENAI_API_KEY or opts.apiKeyEnv.  
--provider bridge: Chrome with --remote-debugging-port=9222.  
lws.so must be built.  

Run: qjsm examples/ollama-repl/repl.js [--provider ollama|gemini|openai|freellm|bridge] [--model NAME] [--host localhost] [--port 11434] [--root .] [--no-stream] [-x] [--failsafe] [--no-tui] [--num-ctx N] [--think [MODE]] [--temperature T] [--max-rounds N] [--yes]  

--model list: prints models; --provider ollama: ollama list; others: /v1/models.  
--num-ctx (default 16384): Ollama context; truncates silently (error: done_reason: "length").  
--think (ollama only): detect (default), on/off/auto/low/medium/high; model rejects 'on'.  
--temperature (0.2): repeatable edits. --max-rounds (40): tool-call caps. --yes: auto-run run_command.

## doc/API.md
# Message/tool-use format rewrite

## Problem  
`GeminiClient#chat()`/`#chatStream()` and `OllamaClient` use flat arrays of `{ role, content }` turns. Ollama's shape lacks support for tool use; Gemini's API supports tool calls but requires specific wire formats. The flat array cannot express tool use, blocking client-level tool calling.

## Research: API tool use  
**Gemini `generateContent`**  
- `Content.role`: only `"user"` or `"model"`; no `"function"` role.  
- `parts`: `{ text }`, `{ functionCall: { name, args } }` in model-role turn, `{ functionResponse: { name, response: object } }` in user-role turn.  
- `tools`: `{ functionDeclarations: [{ name, description, parameters }] }`  
- `toolConfig.functionCallingConfig.mode`: `AUTO` (default), `ANY`, `NONE`  
- Streaming: `functionCall` arrives whole in one SSE event  

**Ollama `/api/chat`**  
- `tools`: `{ type: 'function', function: { name, description, parameters } }`  
- Tool call reply: `message.tool_calls: [{ function: { name, arguments } }]`  
- Tool result: `{ role: 'tool', content: string, tool_name: string }`  
- No `tool_choice` knob; always behaves like `AUTO`  
- Streaming: `tool_calls` appear in intermediate chunks  

## Design: Extended message format  
Callers add:  
- `{ role: 'assistant', content?: string, toolCalls: [{ id, name, args }] }`  
- `{ role: 'tool', name: string, content: string | object, toolCallId?: string }`  

- `toolCalls.id`: synthesized as `${name}#${index}`; never sent over wire  
- `toolCalls.thoughtSignature`: for Gemini 3 models; must be echoed back or return 400  
- `tool.content`: string (common) or object; `GeminiClient` wraps as `{ result: content }`, `OllamaClient` strings with `JSON.stringify`  

`chat()`/`chatStream()` new options:  
- `tools: [{ name, description, parameters }]` – JSON Schema object  
- `toolChoice: 'auto' | 'any' | 'none'` – maps to Gemini; Ollama ig

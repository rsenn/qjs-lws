ollama-repl Project Documentation
================================

Project Overview:
-----------------
ollama-repl: CLI for Ollama, Gemini, OpenAI, freellm via native APIs. Supports file glob/directory detection, auto-imports, file output (File: blocks), tool calls (LIST:/READ:/RUN:), session persistence (session.json, session.log), real line editing, tab completion, thinking quips, tool execution with approval. Uses dedicated HTTP client, token streaming, file exchange tracking, diff saving. Error: "Connection closed: timeout" if silent gap > timeoutSecs.

Commands: /reset, /clear, --provider (ollama/freellm/bridge), --model, --root, --timeoutSecs. Files: lib/ollama-client.js, lib/file-refs.js, lib/file-exchange.js, lib/file-blocks.js, lib/session-store.js, lib/session-log.js, lib/quips.js.

Architecture:
-------------
One QuickJS process, one event loop. No workers. All hooks in repl.js.

Failover Strategy:
-----------------
Provider fallback, skip recovery.

#Callback reasons

Every LWS_CALLBACK_* reason is exposed as an integer constant on the lws module and as a camelCased name (via getCallbackName). Use the named handlers on your protocol descriptor for clarity:

{
  name: 'http',
  onHttp(wsi, uri) { … },
  onClosedHttp(wsi) { … },
}

The list below mirrors lws_callback_names[] in lws.c and documents the JS arguments after wsi.
